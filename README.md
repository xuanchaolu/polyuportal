# PolyU Portal · 2026-27 Sem1

**本平臺旨在為香港理工大學現有的兩個教學平臺未能整合的情況提供簡便可用的解決方案**
一個本地門戶：**左側分層導航，右側直接顯示網頁**。

- 打開後先看到**主頁面**（歡迎頁 + 全部鏈接總覽）
- 點左側任意一條 → 在**右側面板**打開它（或按需要開新標籤）
- 點頂欄 ☰ / 按 `[` 可**收起左側欄**，右側全寬，專心看網頁

> **你只需要一個檔：`portal.html`。** 樣式、腳本、圖示全部已經內嵌在裏面，
> 不依賴任何其他檔，拷到哪都能直接用。

## 快速開始

### 1. 拿到 `portal.html`

- 從 GitHub：點開 `portal.html` → 右上角 **Download raw file**（或點 `Raw` 後另存為）
- 或直接從別人那裏拷貝這個檔

### 2. 打開它

| 用法 | 怎麼做 |
| --- | --- |
| **自己電腦上用**（最簡單） | **雙擊 `portal.html`** |
| 想讓地址固定 | 把它放進一個檔夾，在該檔夾執行 `python3 -m http.server 8321`，再訪問 `http://127.0.0.1:8321/portal.html` |
| 手機 / 多臺設備 | 部署到靜態託管，見[部署到網上](#部署到網上) |

### 3. （可選）裝解鎖擴展

不裝也能正常用——內嵌不進去的站點會自動改用**新標籤**打開。
裝了之後，PolyU 的 Canvas、Learn@PolyU、eStudent 等頁面就能**直接顯示在右側面板裏**：
見[可選：讓校內網頁顯示在右側](#可選讓校內網頁顯示在右側)。

## 怎麼用

### 主頁面

進入後第一眼看到的就是主頁面：

- **左上**：logo、學期徽標、問候語；**右上**：即時時鐘與日期
- **統計卡**：共多少個鏈接、多少個分組、多少個在右側打開、多少個走新標籤
- **最近訪問**：最近點開過的條目（最新的在最前，第一條標「繼續上次」），可一鍵清空
- **全部鏈接**：按分組列出的卡片，點卡片裏的名稱即可打開
- **快捷鍵提示**

### 左側導航

- 點**分組標題**可以折疊 / 展開這一組
- 點**條目**即可打開（默認在右側面板；被設為新標籤的會直接開新標籤）
- 滑鼠移到條目上，右側出現 **↗** 小圖示，點它可**直接開新標籤**，不佔用右側面板

### 頂部工具欄（從左到右）

| 按鈕 | 作用 |
| --- | --- |
| ☰ | 展開側欄（側欄收起時出現） |
| 🏠 | 回到主頁面 |
| ← → | 後退 / 前進（在 portal 裏打開過的條目之間切換） |
| 齒輪 | 打開**設置**：增刪分組與小專案 |
| 膠囊（新標籤 / 嵌入） | 顯示當前條目的打開方式，**點一下即可切換**並記住 |
| ⟳ | 重新加載右側頁面 |
| ⧉ | 複製當前網址 |
| ⛶ | 專注模式：隱藏頂欄與狀態欄 |
| 新標籤打開 | 用流覽器新標籤打開當前頁面 |

### 鍵盤快捷鍵

| 鍵 | 作用 |
| --- | --- |
| `[` | 收起 / 展開左側欄 |
| `/` | 搜索課程代碼、名稱或網址 |
| `H` | 回到主頁面 |
| `F` | 專注模式（再按一次退出） |
| `R` | 重新加載右側頁面 |
| `Alt` + `←` / `→` | 後退 / 前進 |
| `Esc` | 清空搜索 / 關閉設置彈層 |

### 打開方式（三種）

每條鏈接都能單獨設置，頂欄膠囊按鈕和設置裏是**同一個開關**：

| 模式 | 行為 |
| --- | --- |
| **自動**（默認） | 裝瞭解鎖擴展 → 在右側打開；沒裝 → 用新標籤打開 |
| **右側嵌入** | 強制在右側面板打開（萬一站點不讓嵌，會提示並給出一鍵出口） |
| **新標籤** | 直接開新標籤，不佔用右側面板 |

### 其他

- **深色模式**：左側欄底部按鈕切換，選擇會記住
- **側欄寬度**：拖側欄右邊緣調整，寬度會記住
- **打開後自動收起**：左側欄底部的開關，勾上後每次點開鏈接側欄自動收起
- **設置會記住**：分組、鏈接、打開方式、最近訪問、主題等都存在你**本機流覽器**裏

## 添加 / 刪除標籤（分組與小專案）

點頂欄的 **齒輪** → 打開「設置 · 分組與鏈接」。

### 新建一個分組（標籤）

1. 點 **＋ 新建分組**
2. 填名稱（例：`實習` / `AI 工具`），點 **保存**
3. 保存後會**直接接著讓你建這個分組裏的第一個小專案** —— 因為空分組在左側欄不顯示
   （避免出現點不開的空節點），但主頁面會照常列出它

### 新建一個小專案

1. 點 **＋ 新建小專案**（或在某分組標題那行點 **＋專案**，直接建到該組裏）
2. 填寫：

| 字段 | 說明 |
| --- | --- |
| **所屬分組** | 放到哪個分組裏 |
| **名稱** | 左側欄顯示的文字，例：`AMA3640` / `圖書館預約` |
| **網址** | 例：`canvas.polyu.edu.hk/courses/4429`。**不寫 `https://` 會自動補**；只接受 http / https |
| **說明（可選）** | 滑鼠懸停在條目上時顯示 |
| **打開方式** | 自動 / 右側嵌入 / 新標籤，見上文 |

3. 點 **保存**，立刻生效並自動保存

### 修改、排序、刪除

每個分組 / 條目右側都有一排小按鈕：

- **↑ ↓** 上下調序
- **編輯** 改名稱、網址、說明、打開方式，也能**換到別的分組**
- **刪除** 會先彈一次確認條（點「確定刪除」才真的刪；刪分組會連帶刪掉組內所有小專案）

### 恢復默認

設置右上角的 **恢復默認** 把分組和鏈接還原成出廠的 18 個（你自己加的會清掉，不可撤銷），
同時清空打開方式與最近訪問記錄。

> 這些改動只存在**你當前這臺設備的這個流覽器**裏。換電腦、換流覽器、或清空流覽器數據後
> 需要重新添加。想讓它成為所有設備的默認值，見[改代碼](#改代碼進階)。

## 可選：讓校內網頁顯示在右側

### 為什麼需要它

PolyU 的 Canvas、Learn@PolyU、eStudent、POSS 等站點在回應頭裏寫了
`X-Frame-Options` / `frame-ancestors`，等於明確告訴流覽器"不許把我放進 iframe"，
所以不裝擴展時右側只會是一片灰色空白。這不是 portal 的問題，是對方站點的策略。

`extension/` 目錄裏的 **Portal Frame Unlocker** 是給你自己流覽器裝的小擴展，
讓這些頁面能正常顯示在右側面板裏。

### 安裝（Edge / Chrome）

1. 把 `extension` 整個檔夾下載到本地
2. 地址欄打開 `edge://extensions`（Chrome 用 `chrome://extensions`）
3. 打開 **開發者模式**
4. 點 **加載解壓縮的擴展程式**
5. 選擇剛才那個 `extension` 檔夾
6. 回到 portal，**刷新頁面**

裝好後：

- 主頁面 hero 上出現綠色的 **`內嵌已解鎖`** 膠囊
- 原來打不開的課程、申請系統都能在右側正常顯示
- 頂欄可能出現「開發者模式擴展」的小提示氣泡，正常現象，關掉即可

### 不裝會怎樣

portal 照常工作：**嵌不進去的站點會自動改用新標籤打開**，不會讓你對著灰板幹等；
主頁面膠囊會顯示 `內嵌未解鎖` 作為提醒。

### 卸載

`edge://extensions` 裏關掉開關或點「移除」，portal 立刻回到"不裝擴展"的行為。

### 說明與代價

- 擴展只在你自己的流覽器裏生效，只針對 iframe 請求摘掉那兩個回應頭，
  **平時直接訪問這些網站的行為不受影響**
- 它還會把**在 iframe 裏收到的會話 cookie**放寬為 `SameSite=None`，
  否則 Learn@PolyU 會報 `Browser Cookies Disabled`（登錄態進不去）
- 代價：這些被放寬的會話 cookie，從別的網站發起的同名請求也會帶上（CSRF 面變大）。
  這是"讓頁面在面板裏能用"的必要代價
- 換電腦、換流覽器要重新裝一次

## 部署到網上

portal 是**純靜態**的（沒有後端、不需要構建），任何靜態託管都能放：Netlify、Vercel、
Cloudflare Pages、GitHub Pages、自己的伺服器都行。**要傳的只有 `portal.html` 一個檔。**

### Netlify Drop（最省事）

1. 打開 <https://app.netlify.com/drop>
2. 把 `portal.html` 拖進去
3. 拿到網址，例：`https://你的名字.netlify.app/portal.html`

想讓它成為根路徑（訪問 `https://你的名字.netlify.app/` 直接打開）：
**把 `portal.html` 改名成 `index.html` 再拖進去**。

### 命令行

```bash
mkdir my-portal && cp portal.html my-portal/index.html
cd my-portal
npm i -g netlify-cli
netlify deploy --prod --dir=.
```

### Git 自動部署

- 建一個倉庫，放 `portal.html`（想用根路徑就命名為 `index.html`）和 `extension/` 檔夾
- 在 Netlify 裏「Add new site → Import an existing project」選這個倉庫
- 構建命令留空，發佈目錄填 `.`

### 部署後

- **擴展不用改**：portal 用固定 ID 探測擴展，換功能變數名稱也能識別，
  所以部署到任何託管平臺都會顯示 `內嵌已解鎖`（前提是流覽器裏裝了擴展）
- **改了原始檔案要重新合成並重新部署**，否則線上還是舊版本
- **設置不隨部署同步**：你在設置裏加的鏈接存在本地流覽器，只影響你自己

## 常見問題

**右側一片灰色空白？**
站點不允許被嵌入。裝[解鎖擴展](#可選讓校內網頁顯示在右側)即可；
或點一下該站點對應的「以後都新標籤打開」，讓它以後直接開新標籤。

**膠囊顯示「內嵌未解鎖」，但我裝了擴展？**
① 確認擴展處於**啟用**狀態（`edge://extensions`）；
② 刷新 portal 頁面；
③ 如果裝的是舊版本或從別的檔夾裝的，重裝一次擴展檔夾（擴展 ID 已固定，重裝不影響 portal 識別）。

**點了課程卻跳到新標籤了？**
說明當前是"自動"模式且沒檢測到擴展（或該條目被設為新標籤）。
展開側欄 → 齒輪 → 找到該條目 → 打開方式改成「右側嵌入」；
或直接用頂欄膠囊按鈕切換。

**Learn@PolyU 顯示 `Browser Cookies Disabled`？**
裝瞭解鎖擴展並刷新即可（擴展會處理會話 cookie）。若仍報錯，說明流覽器禁止了第三方 Cookie，
這類站點請改用「新標籤打開」。

**登錄進不去 / 要反復登錄？**
流覽器對 iframe 裏的第三方 Cookie 有額外限制。多數情況裝擴展後正常；
若流覽器開啟了"阻止第三方 Cookie / 跟蹤保護"，這類站點用「新標籤打開」更省事。

**雙擊 `portal.html` 時膠囊顯示未解鎖？**
從 `file://` 打開時，擴展的標記腳本默認不注入，此時走"未裝擴展"的回退邏輯（照常可用）。
想讓 `file://` 也識別，在 `edge://extensions` 裏給擴展打開「允許訪問檔網址」；
或用 `python3 -m http.server` 訪問。

**在手機上也能用嗎？**
能打開和使用（部署到託管後訪問網址即可），但手機流覽器裝不了解鎖擴展，
所以校內頁面會以新標籤方式打開。

**我加的鏈接換電腦就沒了？**
配置存在流覽器本地。想長期保留：要麼每臺設備各加一次，要麼把它做成默認值（見下）。

## 改代碼（進階）

日常使用**不需要**看這一節。下麵是如果你想改 portal 本身（換 logo、換配色、改出廠鏈接）：

```
portal.html      ← 成品：唯一需要分發/部署的檔（由下麵幾個檔合成）
index.html       頁面結構
styles.css       樣式、配色變數、深色模式
app.js           全部邏輯：導航、打開方式、設置、主頁面
build-single.py  由上面三個檔 + 兩張圖合成 portal.html
main-logo-1x.png / favicon.png   logo 與網頁圖示
extension/       可選的流覽器擴展（讓校內頁面能嵌進右側）
TECHNICAL.md     技術參考：可嵌入性的實測依據、cookie 處理、擴展探測機制
```

改完原始檔案後**重新合成單檔版**：

```bash
cd portal
python3 build-single.py
```

（腳本會把 CSS / JS / 兩張圖片內嵌進 `portal.html`，並在寫出前自檢沒有遺漏的外部引用。）

- **換 logo**：替換 `main-logo-1x.png`（建議寬高比接近 334×64）。深色模式下 portal 會自動
  墊一層淺色底板；檔缺失會自動回落到文字版品牌。網頁圖示是 `favicon.png`。
- **換主題色**：改 `styles.css` 開頭的 `--accent` 系列變數（淺色 / 深色各一套）。
- **改出廠鏈接**（所有設備的默認值）：改 `app.js` 頂部的 `DEFAULT_NAV`：

```js
{
  id: 'ai',                     // 唯一 id
  title: 'AI',                  // 分組名
  items: [
    { id: 'deepseek',           // 唯一 id
      code: 'Deepseek',         // 顯示名稱
      sub: 'AI 平臺 · 用量',     // 說明（懸停顯示）
      kind: 'ai',               // 角標類型：canvas / learn / polyu / apply / ai / web / custom
      frame: 'login',           // no=禁嵌入 / yes=可嵌入 / login=需登錄，省略=未知
      url: 'https://platform.deepseek.com/usage' }
  ]
}
```

> `DEFAULT_NAV` 只在"用戶沒自定義過"時使用。已經用過 portal 的流覽器裏存了 `nav`，
> 想讓新默認生效，需要點一次設置裏的 **恢復默認**（或在介面上手動加）。
